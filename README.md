# Дәрігерге онлайн жазылу жүйесі (Doctor Appointment System)

## 📌 Жоба туралы
Бұл веб-қосымша пациенттерге дәрігерлерді қарауға, мамандығы бойынша іздеуге және қабылдауға онлайн жазылуға мүмкіндік береді. 
Жоба PHP және MySQL технологиялары арқылы жасалған.

## 🚀 Негізгі мүмкіндіктері
- Пайдаланушыларды тіркеу және авторизациялау (Login/Register).
- Дәрігерлер тізімін көру, аты мен мамандығы бойынша сүзу (Filter/Search).
- Дәрігерге ыңғайлы күн мен уақытқа жазылу (Create).
- Жеке кабинетте жазылуларды көру және жою (Read/Delete).

## 📄 Беттер тізімі
1. `index.php` - Басты бет (Дәрігерлер тізімі және іздеу)
2. `login.php` / `register.php` - Тіркелу және кіру беттері
3. `appointment.php` - Дәрігерге жазылу формасы
4. `dashboard.php` - Пациенттің жеке кабинеті

## 🗄 Дерекқор құрылымы (Database Structure)
Жобада 3 негізгі кесте қолданылады:
- `users` - Пайдаланушылар ақпараты
- `doctors` - Дәрігерлер ақпараты
- `appointments` - Қабылдауға жазылулар

## 🛠 Технологиялар
- HTML5, CSS3, Bootstrap 5
- PHP 8.x
- MySQL
